# 0.1 实现与验证状态

## 已写入的功能

- 五个原生 SwiftUI 页面，英韩独立空间与首次引导。
- 每种语言的学习目标、自报水平、每日时间；每日任务从真实学习事件计算，并参考近期错误给出表达建议。
- 文字对话、会话记录、待回复/待反馈状态持久化、取消与重试；结束后显示纠错、原因、下一步练习，并可保存 AI 建议词汇。
- 明确标注的本地规则练习与独立的真实 AI 网络客户端。两者不会静默互换。
- 12 个双语种子词条，自建词条、搜索、收藏、间隔复习、到期队列与来源标记。
- 4 组原创专项、共 12 道客观题，覆盖 IELTS / CET-6 / TOPIK I / TOPIK II 的阅读主题练习；不是完整模拟试卷。
- 自动判分、原文和逐题解析、作答草稿、成绩历史；不换算官方分数。
- 实际学习事件、连续天数、纠错本、历史导出、对话清除与全部本地数据删除。
- 服务端默认接入 DeepSeek `deepseek-flash` 的兼容接口；包含结构化校验、具体引文验证、短期私人令牌、限流和去重。真实英韩模型回复和纠错已通过，见 `docs/demo-ai.md`。

## 与第一阶段方案相比的实施决定

本地存储首版采用 **带版本号的 Codable JSON + 原子写入**，而非 SwiftData。原因是当前为单人、小规模离线资料，整体快照更便于在 Linux 测试业务与损坏恢复，同时不引入未验证的 SwiftData 运行时依赖。SwiftUI 使用独立 `AppStore`，核心层不依赖界面，将来可将存储实现替换为 SwiftData。

当前只支持 schema v1，遇到未知版本或损坏文件会停止写入并提供导出/备份恢复入口，不声称已经实现所有未来迁移。大词库、复杂检索和多设备同步时需要升级存储方案。

公开用户认证也未提前建设：当前后端仅供个人封闭试用，令牌通过设置手动输入、保存在 Keychain，最长有效期 7 天。没有将长期密钥嵌入 App。公开 TestFlight / 多用户上线前仍需账户鉴权与持久化额度管理。
